# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)

## 26.11.11 (2026-11-11)

### Added

- Core framework: `xbiont` command dispatcher executing actionable scripts driven by `X_` environment variables
- Runtime commands for system, session and zram management
- Image lifecycle: template generation and containerized kiwi-ng builds producing live ISOs
- Support for Debian 11/12/13, CentOS 10 and Fedora 43/44, with KDE Plasma, Trinity and console seats
- Prototype guided system installer
